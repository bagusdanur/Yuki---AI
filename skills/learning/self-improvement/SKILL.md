# Skill: Self-Improvement & Continuous Learning

Gunakan skill ini ketika:
1. Menemukan bug atau pelajaran coding penting (misalnya penanganan touch pada game canvas, parameter API, atau optimasi logika).
2. Menyelesaikan perbaikan arsitektur atau tugas kompleks dan ingin menyimpan catatan pengalaman ke database memori jangka panjang.
3. Mengakses atau membaca wawasan/pelajaran masa lalu (`list_self_improvements`).
