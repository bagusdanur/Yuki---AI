Privasi pengguna

Yuki menyimpan nama, riwayat percakapan, preferensi, perkembangan hubungan, catatan, jadwal, artifact, workspace, dan feedback agar layanan dapat berlanjut secara konsisten.

Penggunaan data

Data digunakan untuk memberikan respons, mengingat konteks, menjalankan fitur yang diminta, menjaga karakter, dan mengevaluasi kualitas layanan. Jangan mengirim kata sandi, informasi pembayaran, atau data yang sangat sensitif melalui chat.

Retensi

Data akun disimpan selama akun masih aktif atau sampai pengguna menghapusnya. Checkpoint approval Agent kedaluwarsa setelah 24 jam. Log operasional hanya berisi metadata aman, bukan prompt, token, cookie, atau isi credential.

Penyimpanan dan kontrol

Kunci ingatan baru disimpan sebagai hash di server dan ditampilkan tersamarkan pada perangkat. Jaga kunci asli tetap pribadi. “Mulai hubungan baru” hanya menghapus sesi lokal perangkat; “Hapus seluruh data” menghapus data server setelah dua tahap konfirmasi.

Operasional

Statistik agregat seperti jumlah pengguna, pesan, error, dan feedback dapat dipantau oleh pengelola. Dashboard tidak menampilkan isi percakapan.

Perubahan

Kebijakan dapat diperbarui ketika layanan berkembang. Versi ini berlaku sejak September 2026.
